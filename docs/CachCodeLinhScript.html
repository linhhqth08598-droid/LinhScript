Cách code LinhScript — Làm Web & Giao diện bằng HQL

Hướng dẫn đầy đủ: từ khởi động máy chủ, viết giao diện HTML, xử lý form, đọc cơ sở dữ liệu, cho tới đóng gói chạy trên Tomcat.

01Tổng quan

Java có JSP + Servlet. HQL có HQLSP + Servlet.hql — ý tưởng giống hệt, chỉ khác cú pháp bên trong thẻ.

Java WebHQL WebGhi chú
index.jspindex.hqlspTrang giao diện
BaoCaoServlet.javaBaoCaoServlet.hqlXử lý logic
out.println("<h1>")printWeb("<h1>")In ra trình duyệt
<%= ... %><%= ... %>Y hệt nhau
request.getParameter("ten")param("ten")Đọc tham số
${pageContext.request.contextPath}webContext()Tên project
Text Block """...""""""..."""Y hệt nhau
web.xmlKhông cầnĐịnh tuyến theo quy ước tên file

Có 3 cách sinh ra một trang web trong HQL, dùng lẫn lộn thoải mái trong cùng project:

  1. HQLSP — file .hqlsp: viết HTML là chính, chèn HQL vào giữa. Hợp cho giao diện.
  2. Servlet — file <Tên>Servlet.hql: viết HQL là chính, in HTML ra. Hợp cho xử lý logic / báo cáo.
  3. Route hàm — webRoute("/duong-dan", "tenHam"): gắn thẳng một hàm vào URL. Hợp cho API JSON.

02Chuẩn bị & chạy

Trình thông dịch HQL biên dịch bằng JDK 21, nên khi chạy cũng phải dùng Java 21. File run.bat ở gốc project đã lo sẵn việc chọn đúng bản Java và nạp toàn bộ jar trong thư mục lib\:

run.bat
@echo off
chcp 65001 >nul

rem --- Chon JVM: uu tien JAVA_HOME, neu khong co thi dung D:\JDK (Temurin 21) ---
set "JAVA_EXE=%JAVA_HOME%\bin\java.exe"
if not exist "%JAVA_EXE%" set "JAVA_EXE=D:\JDK\bin\java.exe"
if not exist "%JAVA_EXE%" set "JAVA_EXE=java"

set "CP=out\production\NgonNguLapTrinhMoi;lib\*"

"%JAVA_EXE%" -Dfile.encoding=UTF-8 -classpath "%CP%" me.hql.script.LinhScriptRunner %*

Chạy website:

.\run.bat web.hql

Máy chủ chặn tuyệt đối kiểu tấn công ../../ để thoát ra ngoài thư mục gốc, và không bao giờ trả mã nguồn .hql ra trình duyệt — gõ thẳng /BaoCaoServlet.hql sẽ nhận lỗi 403.

04File main web.hql

Đây là nơi duy nhất chứa cấu hình. Ai cài thư viện HQL về máy khác cũng chỉ cần sửa đúng 3 dòng đầu.

web.hql
use hql.web;
use hql.time;
use hql.util;

// ------- CẤU HÌNH — CHỈ CẦN SỬA 3 DÒNG NÀY -------
var TEN_PROJECT = "/QuanLyKho";   // -> http://localhost:8080/QuanLyKho
var CONG        = 8080;
var THU_MUC_WEB = "web";          // thư mục chứa .hqlsp / .html / <Ten>Servlet.hql

// ------- Route viết tay: trả JSON cho /api/sanpham -------
func apiSanPham() {
    var ds = ["Laptop", "Phone", "Tablet"];
    webJson(ds);
}
webRoute("/api/sanpham", "apiSanPham");

// Khởi động máy chủ — bảng đường dẫn sẽ tự in ra ngay bên dưới
webStart(CONG, TEN_PROJECT, THU_MUC_WEB);
webWait();
LệnhÝ nghĩa
webStart(cong, "/ten", "thuMuc") Khởi động máy chủ. Bắt buộc có tên project (tham số 2). Tham số 3 tuỳ chọn — bỏ qua thì mặc định là thư mục web.
webWait() Giữ chương trình chạy mãi. Nếu thiếu, chương trình chạy xong sẽ thoát và tắt luôn máy chủ.
webStop()Tắt máy chủ bằng lệnh.
webRoot("web")Đổi thư mục gốc mà không cần khởi động máy chủ (dùng cho deploy.hql).
Lưu ý

Tên project tự động được chuẩn hoá: viết "QuanLyKho" hay "/QuanLyKho/" đều thành /QuanLyKho. Để trống sẽ báo lỗi ngay lúc khởi động.

05Cơ chế định tuyến — URL nào chạy file nào?

Khi có một yêu cầu tới, máy chủ dò theo đúng thứ tự sau, gặp cái nào khớp trước thì dùng cái đó:

  1. Đường dẫn đã gán bằng webRoute("/abc", "tenHam") → gọi hàm HQL.
  2. Đường dẫn đã gán bằng webServlet("/abc", "XyzServlet.hql") → chạy file đó.
  3. URL kết thúc bằng / → tìm index.hqlsp, rồi index.html, rồi index.htm.
  4. URL kết thúc bằng .hqlsp → chạy thẳng file đó.
  5. Quy ước servlet: /BaoCao → tìm BaoCaoServlet.hql.
  6. File tĩnh có thật (css, js, png, jpg, svg, ico, json, txt...) → trả nguyên file.
  7. Gõ thiếu đuôi: /trangchu → thử trangchu.hqlsp, .html, .htm.
  8. Không khớp gì cả → trang lỗi 404.

Quy ước tìm file servlet

Với URL /baocao hoặc /BaoCao, máy chủ lần lượt thử các tên BaoCaoServlet.hql rồi baocaoServlet.hql — tìm trong 4 nơi:

  • Thư mục cùng cấp với URL (ví dụ /admin/BaoCao → tìm trong web/admin/)
  • Thư mục gốc web/
  • web/servlets/
  • web/WEB-INF/hql/
Nghĩa là

Chỉ cần đặt file SanPhamServlet.hql vào web/ là tự động có URL /QuanLyKho/SanPham — không phải khai báo gì thêm.

07Servlet .hql

Đặt tên file theo đúng quy ước <Tên>Servlet.hql là xong — URL sẽ là /<Tên>. Bên trong viết các hàm giống hệt Servlet của Java.

HàmChạy khi nào
init()Đúng 1 lần lúc servlet được nạp vào bộ nhớ
doGet()Truy cập bằng phương thức GET (gõ URL, bấm link)
doPost()Truy cập bằng POST (gửi form method="post")
doQuery()Truy cập bằng phương thức HTTP QUERY (chỉ đọc như GET nhưng có body; client gọi httpQuery(url, body))
service()Dự phòng — chạy nếu không có doGet/doPost tương ứng
web/BaoCaoServlet.hql → /QuanLyKho/BaoCao
use hql.web;
use hql.database;

// --- OOP: dùng class y hệt Java, thuộc tính có @ là public ---
class SanPham {
    var @ten;
    var @gia;
    var @kho;

    func @init(t, g, k) {
        this.@ten = t;
        this.@gia = g;
        this.@kho = k;
    }
    func @thanhTien() { return this.@gia * this.@kho; }
    func @trangThai() { return this.@kho > 0 ? "Còn hàng" : "Hết hàng"; }
}

func init() {
    print("[SERVLET] BaoCaoServlet.hql đã được nạp vào bộ nhớ.");
}

func doGet() {
    // Viết cả khối HTML bằng chuỗi 3 nháy """ giống Text Block của Java
    printWeb("""
        <!doctype html>
        <html lang="vi">
        <head><meta charset="utf-8"><title>Báo cáo kho</title>
    """);
    printWeb("<link rel='stylesheet' href='" + webContext() + "/style.css'>");
    printWeb("</head><body><h1>Báo cáo kho hàng</h1>");

    var sp = new SanPham("Laptop", 1200, 5);
    printWeb("<p>" + htmlEscape(sp.@ten) + " — " + sp.@thanhTien()
             + " USD — " + sp.@trangThai() + "</p>");

    printWeb("<a href='" + webContext() + "/'>&larr; Về trang chủ</a>");
    printWeb("</body></html>");
}

func doPost() {
    webType("text/plain; charset=UTF-8");
    printWeb("Đã nhận POST với ten = " + param("ten", "(trống)"));
}
Tiện

Mỗi servlet có vùng hàm/lớp riêng — hai file servlet cùng đặt tên doGet() hay cùng khai class SanPham đều không đụng nhau.

08Route hàm & API JSON

Không muốn tạo file riêng thì gắn thẳng một hàm trong web.hql vào URL:

func apiSanPham() {
    var ds = ["Laptop", "Phone", "Tablet"];
    webJson(ds);            // tự đặt contentType = application/json
}
webRoute("/api/sanpham", "apiSanPham");

webJson() nhận cả mảng lẫn map, tự đổi sang JSON:

func apiChiTiet() {
    var sp = {
        "ten": "Laptop Dell",
        "gia": 1200,
        "conHang": true,
        "mau": ["Đen", "Bạc"]
    };
    webJson(sp);
}
webRoute("/api/chitiet", "apiChiTiet");

Trả về:

{"ten":"Laptop Dell","gia":1200,"conHang":true,"mau":["Đen","Bạc"]}

Gán servlet vào URL tuỳ ý

Nếu không thích quy ước tên file, dùng webServlet():

webServlet("/bao-cao-kho", "BaoCaoServlet.hql");
// Giờ mở /QuanLyKho/bao-cao-kho cũng chạy đúng file đó

09CSS, ảnh và file tĩnh

10Form & dữ liệu người dùng

web/DangNhapServlet.hql
use hql.web;

func doGet() {
    webRedirect(webContext() + "/");     // vào thẳng bằng GET thì đá về trang chủ
}

func doPost() {
    var tk = param("taiKhoan");
    var mk = param("matKhau");

    if (tk == "admin" && mk == "123") {
        sessionSet("nguoiDung", tk);
        webRedirect(webContext() + "/");
    } else {
        webStatus(401);
        printWeb("<p style='color:#ce2c4b'>Sai tài khoản hoặc mật khẩu!</p>");
        printWeb("<a href='" + webContext() + "/'>Quay lại</a>");
    }
}
Chống XSS — bắt buộc

Mọi thứ người dùng nhập vào, khi in ra HTML phải bọc htmlEscape(). Nếu không, họ gõ <script>...</script> vào ô input là chạy được mã độc trên trang của bạn.

11Session & Cookie

Session — nhớ dữ liệu theo từng người dùng

<%  var luot = sessionGet("luot");
    if (luot == null) { luot = 0; }
    luot = luot + 1;
    sessionSet("luot", luot); %>
<p>Bạn đã tải trang này <b><%= luot %></b> lần trong phiên hiện tại.</p>
HàmCông dụng
sessionSet(khoa, giaTri)Lưu giá trị vào phiên

sessionDel(khoa)Xoá 1 khoá
sessionId()Mã phiên hiện tại
sessionKill()Huỷ cả phiên (đăng xuất)

Kiểm tra đăng nhập

<%  var nguoiDung = sessionGet("nguoiDung");

Cookie — nhớ lâu hơn, kể cả sau khi tắt trình duyệt

var mau = cookieGet("mauNen");

12Kết nối SQL Server

Driver JDBC đã nằm sẵn trong lib\mssql-jdbc-13.4.0.jre11.jar và được run.bat nạp tự động.

web/BaoCaoServlet.hql (phần đọc CSDL)
use hql.web;
use hql.database;

func doGet() {
    printWeb("<h1>Báo cáo kho hàng</h1>");

    var ok = connect("localhost", 1433, "DemoDB", "sa", "123");

    if (ok) {
        printWeb("<table><tr><th>Sản phẩm</th><th>Giá</th><th>Tồn</th></tr>");

        for dong in query("SELECT ProductName, Price, Stock FROM Products") {
            printWeb("<tr><td>" + htmlEscape(dong.ProductName) + "</td>");
            printWeb("<td>" + dong.Price + "</td>");
            printWeb("<td>" + dong.Stock + "</td></tr>");
        }
        printWeb("</table>");

        var soKhach = queryValue("SELECT COUNT(*) FROM Customers");
        printWeb("<p>Tổng số khách hàng: <b>" + soKhach + "</b></p>");

        closeDB();
    } else {
        printWeb("<p class='loi'>Không kết nối được CSDL: "
                 + htmlEscape(dbError()) + "</p>");
    }
}

Truy cập cột bằng dấu chấm: dong.ProductName — đúng tên cột trong câu SQL.

Chống SQL Injection

Khi câu lệnh có dữ liệu người dùng nhập, đừng nối chuỗi. Dùng querySafe() / executeSafe() với dấu ?:

// SAI — người dùng gõ:  ' OR '1'='1  là lộ hết dữ liệu
var kq = query("SELECT * FROM Products WHERE Name = '" + param("q") + "'");

// ĐÚNG
var kq = querySafe("SELECT * FROM Products WHERE Name = ?", param("q"));
